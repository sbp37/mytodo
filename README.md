# mytodo — 의뢰서 마감 트래커 (기획안)

시즌 FG 개발의뢰서를 **마감 안에, 짧고 굵게** 끝내기 위한 개인용 웹앱.
아직 코드는 없고, 이 문서는 기획 초안입니다.

---

## 1. 해결하려는 문제

- 할 일이 많으면 뭐부터 할지 몰라 헤매다가 막판에 몰아서 끝냄
- 한 건 잡으면 "세월아 네월아" — 짧게 집중하는 게 어려움
- 파일명(`27SS_8PNOVA_TYLA270803.ai`)만으로는 어떤 의뢰서인지 헷갈림 → **이미지로 보고 골라야 함**

## 2. 핵심 화면 4개

### ① 시즌 대시보드
- 마감일(예: 11/3) D-day, **오늘 꼭 끝내야 할 개수** 크게 표시
- 컨셉별 게이지바 + 숫자: `8P 비눗방울 노바 ███░░░░ 5 / 35 (14%)`
- 페이스 상태: `여유 / 정상 / 위험` (지금 속도로 가면 며칠에 끝나는지 예측)

### ② 의뢰서 갤러리 (이미지로 보기)
- 컨셉별 탭, 썸네일 카드 그리드
- 카드: 썸네일 · 코드(`TYLA270803`) · 상태(대기/진행/완료) · 난이도(S/M/L)
- 비슷한 의뢰서는 **품목 코드로 자동 묶음** (아래 4번 참고)

### ③ 오늘 할 일 + 집중 타이머
- 아침에 갤러리에서 오늘 할 의뢰서를 탭해서 담기 (앱이 추천 개수 제시)
- 한 건 시작 → 큰 타이머 화면 (해당 의뢰서 이미지 같이 띄움)
- 완료 누르면 자동 기록: `14:05 ~ 14:17 · 12분 · 빡집중 +30`
- "다음 하나만" 버튼: 뭐 할지 고민 없이 앱이 바로 다음 건을 띄워줌

### ④ 하루 마감 리포트
```
오늘의 업무 점수 135점
  완료 4개                 +40
  빡집중(15분 이내) 3건      +90
  목표 미달 (5개 중 4개)     -
  연속 달성 0일

⚠ 오늘 1개 밀림 → 남은 14일 하루 목표 6개 → 7개 (내일부터)
```

## 3. 계산 규칙

**하루 목표** = `ceil(남은 개수 ÷ 남은 작업일수)` — 매일 자동 재계산
- 작업일: 주말 제외 / 포함 선택, 휴가·외근일 수동 제외 가능
- 오늘 못 한 만큼 남은 날에 다시 나눠서, "어제 2개 밀려서 목표가 6→7개" 처럼 **원인을 같이 보여줌**

**집중 점수** (난이도별 기준시간 대비)

| 소요 시간          | 점수        |
|-------------------|------------|
| 기준시간 이내 (기본 15분) | +30 빡집중 |
| 기준 × 2 이내       | +15        |
| 기준 × 3 이내       | +5         |
| 그 이상            | 0          |

- 의뢰서마다 난이도가 달라서(키링 vs 복잡한 티셔츠) S/M/L 별로 기준시간을 따로 둠 (예: S 10분 · M 15분 · L 25분)
- 기본 완료 +10, 하루 목표 달성 보너스 +50, 연속 달성일 streak
- 보상 상점: 점수로 내가 정한 보상 교환 (예: 300점 = 커피, 1000점 = 반차 기분 내기)

## 4. 의뢰서 이미지 / 자동 묶음 — 가능 여부

**① `.ai` 파일을 그대로 끌어다 놓기 (추천)**
일러스트레이터 파일은 기본 저장 옵션("PDF 호환 파일 만들기")이면 내부가 PDF라서
브라우저에서 바로 첫 페이지를 썸네일로 렌더링할 수 있음 (pdf.js).
- 파일명에서 자동 추출: `27SS_8PNOVA_TYLA270803.ai` → 시즌 27SS / 컨셉 8P NOVA / 코드 TYLA270803
- 파일은 **내 브라우저 안에서만 처리**, 회사 디자인 파일이 외부 서버로 올라가지 않음

**② PPT 올리기**
- `.pptx`는 내부에 이미지가 들어 있어서 이미지 추출은 가능
- 다만 슬라이드 전체를 원본 그대로 그리는 건 브라우저에서 부정확함
  → PPT를 **PDF로 내보내서 올리면** 슬라이드별 이미지로 정확하게 띄울 수 있음

**자동 묶음 규칙** — 파일명 코드 구조 활용
```
TY  LA  27  08  03
│   │   │   │   └ 순번
│   │   │   └ 컨셉 페이지 (6P / 7P / 8P)
│   │   └ 시즌 (27)
│   └ 품목 코드 (LA, RW, WH, TC, TM, RN, OW, YW, TJ, MW, MZ, KC ...)
└ 브랜드 접두
```
같은 품목 코드끼리 묶어서 연달아 처리하면 작업 전환 비용이 줄어듦.
품목 코드 → 한글 이름(예: RW = ○○)은 처음 한 번만 직접 지정.

## 5. 기술 방향 (초안)

- 웹앱 (React + Vite), 맥 브라우저 기준
- 데이터는 브라우저 저장소(IndexedDB) — 서버·로그인 없이 시작
- 배포: GitHub Pages 또는 Vercel (무료)
- 나중에 폰에서도 체크하고 싶으면 그때 동기화 추가

## 6. 만드는 순서

1. 컨셉/의뢰서 등록 (파일 드래그 → 썸네일 + 자동 분류) + 대시보드 게이지
2. 하루 목표 자동 계산 + 밀린 개수 재분배 표시
3. 오늘 할 일 + 집중 타이머 + 시간 기록
4. 하루 마감 리포트 + 점수 + 보상
